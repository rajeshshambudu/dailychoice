
# Daily Choice Website

**Tagline:** Better Choices, Brighter Tomorrow.

## About

Daily Choice is a peanut products brand based in Nizamabad,
Telangana, India.

## Technology

- HTML5
- CSS3
- JavaScript ES Modules
- GitHub Pages

## Project Structure

- index.html — Main website
- assets/css/style.css — Website styling
- assets/js/config.js — Business configuration
- assets/js/products.js — Product information
- assets/js/cart.js — Enquiry cart
- assets/js/main.js — Website functionality
- assets/images/ — Website images

## Before Launch

1. Configure the official WhatsApp number.
2. Verify the FSSAI licence details.
3. Upload the official logo and product images.
4. Confirm product sizes and descriptions.
5. Add the actual domain.
6. Test the website on mobile and desktop.
